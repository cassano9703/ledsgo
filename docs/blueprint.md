# **App Name**: Leds Go Configurator

## Core Features:

- Neon Sign Customization: Allow customers to customize their LED signs with different fonts, sizes, and colors based on the Printymex example.
- Real-time Preview: Display a real-time preview of the customized LED sign.
- AI-Powered Design Suggestions: AI tool which suggests design options or improvements to the customer's design based on current trends.
- Order Placement: Enable customers to place orders for their customized LED signs.
- Catalog of premade designs: Browse from and customize premade LED signs that can be bought immediately.

## Style Guidelines:

- Primary color: Electric blue (#7DF9FF) to evoke the vibrancy and energy of LED lights, aligning with the advertising nature of the business.
- Background color: Light gray (#EEEEEE) for a clean and modern look, ensuring the colorful LEDs stand out.
- Accent color: Soft purple (#BE95C4) to complement the primary color and add a touch of sophistication.
- Body and headline font: 'Poppins' for a geometric, contemporary, fashionable feel. Note: currently only Google Fonts are supported.
- Use modern, minimalist icons related to customization options and features.
- A clean and modern layout with clear calls to action for customization and ordering.
- Subtle animations to highlight customization options and provide visual feedback.
